# ⚽ SPORT ZONE - المنصة الرياضية العربية الأولى

موقع رياضي حديث واحترافي متكامل مصمم باللغة العربية مع دعم كامل لاتجاه **RTL** والوضع الداكن **Dark Mode**. يعرض الموقع المباريات المباشرة، آخر الأخبار، ترتيب الدوريات العالمية والعرية، الفيديوهات الرياضية، وتفاصيل الفرق واللاعبين بتصميم جذاب وسريع الاستجابة.

---

## 🌟 أبرز المميزات

- **تصميم رياضي فاخر (Mobile First)**: واجهة مستخدم ناعمة وسريعة تتطابق مع أفضل المواقع الرياضية العالمية (مثل Sky Sports و Marca و BBC Sport).
- **الوضع الداكن Dark Mode كخيار أساسي**: مريح للعين مع ألوان نيون حيوية (أخضر زمردي، أزرق كهربائي، برتقالي ناري).
- **شريط أخبار عاجلة متحرك Ticker**: يعرض أحدث المستجدات فور حدوثها مع التوقف المؤقت عند تحريك الماوس فوقه.
- **تغطية شاملة لجميع المسابقات**:
  - دوري أبطال أوروبا
  - الدوري الإنجليزي الممتاز
  - الدوري الإسباني (الليغا)
  - الدوري الإيطالي (الكالتشيو)
  - الدوري الفرنسي
  - أخبار المنتخبات العربية والعالمية
- **نظام المباريات المباشرة LIVE Match Center**:
  - عرض مباريات اليوم، الغد، والنتائج السابقة.
  - مؤشر LIVE تفاعلي للألعاب الجارية مع عداد الدقائق.
  - نافذة التفاصيل (تشكيلة الفريقين، الإحصائيات، والأحداث).
- **صفحات خاصة بالفرق واللاعبين**: استعراض معلومات الأندية والسيرة الذاتية والبطولات وإحصائيات اللاعبين (مثل محمد صلاح وفينيسيوس جونيور).
- **مكتبة الفيديوهات الرياضية**: مشغل فيديو منبثق لمشاهدة ملخصات المباريات وأجمل الأهداف.
- **البحث المباشر (Ctrl + K)**: بحث فوري باللغة العربية عن المقالات والأندية واللاعبين.
- **نظام تعليقات تفاعلي**: إمكانية كتابة التعليقات والتفاعل مع الأخبار مباشرة.
- **تحسين SEO وتجاوبية 100%**: دعم Open Graph, Sitemap, Robots.txt و Structured Data.

## 🚀 طريقة التشغيل محلياً (Local Execution)

لا يتطلب المشروع أي تعقيد أو إعدادات مدفوعة:

### الخيار 1: باستخدام Python (أسهل طريقة)
افتتح مبدل الأوامر في مجلد المشروع وشغل:
```bash
python -m http.server 8000
```
ثم افتح المتصفح على العنوان: `http://localhost:8000`

### الخيار 2: باستخدام Node / Live Server
إذا كان لديك `npx` أو إضافة Live Server في VS Code:
```bash
npx serve .
```

## 🌐 طريقة النشر المجاني بالكامل (Free Deployment)

الموقع صُمم ليكون جاهزاً للنشر بضغطة زر مجاناً على أحد الخدمات التالية:

### 1. Vercel Free
- قم برفع المجلد على حسابك في GitHub.
- توجه إلى [Vercel](https://vercel.com) واضغط **Add New Project**.
- اختر المستودع واضغط **Deploy**.

### 2. Cloudflare Pages
- ادخل إلى حسابك في [Cloudflare Pages](https://pages.cloudflare.com).
- اختر **Create a Project** وربطه بـ GitHub.
- قم بتحديد المسار الرئيسي ثم اضغط **Save and Deploy**.

### 3. Netlify Free
- يمكنك سحب المجلد `sport-zone` وإسقاطه في خانة [Netlify Drop](https://app.netlify.com/drop).
- سيعطيك رابطاً شاملاً لموقعك مجاناً خلال ثوانٍ.

### 4. GitHub Pages
- من إعدادات مستودعك في GitHub، اذهب إلى قسم **Pages**.
- اختر الـ Branch `main` ثم اضغط **Save**.

## 🔄 كيفية استبدال Mock Data بـ API رياضي حقيقي مستقبلياً

تم بناء طبقة البيانات في `js/apiService.js` بنمط Abstracted Service Pattern لربط أي API رياضي (مثل Football-Data.org أو API-Football) بكل سهولة:

1. افتح الملف `js/apiService.js`.
2. قم بتعديل الإعدادات في أعلى الملف:
```javascript
export const API_CONFIG = {
  USE_REAL_API: true, // تغييرها إلى true
  API_KEY: "ضع_مفتاح_الـ_API_الخاص_بك_هنا",
  BASE_URL: "https://api.football-data.org/v4"
};
```
3. إضافة دالة جلب البيانات من الـ Endpoints الحقيقية داخل الدوال الحالية مثل `getMatches()` أو `getStandings()` وسيقوم الموقع بعرض البيانات المباشرة فوراً دون الحاجة لتغيير أي مكون في الواجهات.
